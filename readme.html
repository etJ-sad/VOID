Validation Of Industrial Devices

What is VOID?

A robot that tests your industrial PCs automatically

VOID (Validation Of Industrial Devices) is like a smart robot that checks if your IPC hardware works correctly. You give it an IPC, wait 48 hours, and it tells you: "GO - this IPC is good" or "NO-GO - there's a problem".

Simple Goal: Put IPC in → Wait 48 hours → Get answer: Good or Bad?

What VOID Does

Tests Everything Automatically
Checks CPU, RAM, GPU, hard drives, USB ports, sensors - everything. No manual work needed.
Uses AI to Find Problems
Like a smart detective - finds problems you might miss. Then says: "This is good" or "This is broken".
Makes Reports
Creates different types of reports: for computers (JSON), for people (web page), and for printing (PDF).
Works Without Internet
No cloud, no internet needed. Everything runs on your local network. Safe and secure.

Project Management

Testing many IPCs at once

Imagine you have 10 IPCs to test. VOID can test them all at the same time. It's like having 10 robots working in parallel. One central computer controls everything.

What It Does

  • Auto Setup: Automatically installs test software on all IPCs
  • Smart Planning: Makes sure all tests finish in 48 hours
  • Many IPCs: Test 10, 20, or 100 IPCs from one place
  • Settings: Change test settings for all IPCs at once
  • History: Keeps track of what was tested and when

How VOID Works Inside

Four simple steps

Think of VOID like a factory with 4 stations. Each station does one job. This makes it simple to understand and easy to fix if something breaks.

Step 1: Look at Hardware

VOID looks at what hardware the IPC has:

  • Find Everything: What CPU? How much RAM? What GPU?
  • Pick Tests: Decides which tests to run based on what it found
  • Make Plan: Plans to finish in 48 hours
  • Nothing Forgotten: Makes sure to test everything important

Step 2: Prepare Tests

VOID prepares what each test will do:

  • Check Ready: Is everything ready to test? Drivers installed?
  • Test List: CPU stress, RAM patterns, GPU compute, disk speed, network
  • Test Recipe: Setup → Run Test → Check if OK → Clean up → Write down results
  • Know What's Good: Has baseline data to compare: "Is this normal or broken?"

Step 3: Run Tests

VOID actually runs all the tests:

  • 8 Tests at Once: Runs multiple tests in parallel to save time
  • Shows Progress: You can see what's happening in real-time
  • Smart Retry: If a test fails, tries again to be sure
  • Can Resume: If power goes out, continues where it stopped

Step 4: Talk to Hardware

VOID connects to all the hardware:

  • Talks to Everything: CPU, RAM, GPU, Hard Drives, USB, Network, Sensors, Security Chips
  • Uses Standard Tools: MemTest86, CrystalDiskMark, HWiNFO, and many more
  • Translation Layer: Like a universal translator - makes all tools speak the same language

The Smart Brain (AI)

How VOID thinks

This is VOID's brain. It uses artificial intelligence to look at test results and find problems. Think of it like a smart doctor looking at your blood test - it knows what's normal and what's not.

Finding Problems

VOID uses 4 different methods to find problems:

  • Method 1: Finds weird values that don't fit the pattern
  • Method 2: Compares with thousands of good IPCs it saw before
  • Method 3: Looks for unusual combinations of errors
  • Method 4: Simple math - is this value too high or too low?

Using 4 methods means VOID catches more problems than using just one method.

Understanding Patterns

VOID looks for patterns in the data:

  • Over Time: Is temperature going up slowly? That's bad!
  • Connections: "When CPU gets hot, fan should speed up - but it didn't!"
  • Trends: "This hard drive is getting slower every hour"
  • Why Failed: Not just "it failed" but "it failed because the fan stopped"

This helps you fix the real problem, not just treat symptoms.

Final Decision

VOID makes the final decision: GO or NO-GO

  • Critical Failures: If something critical is broken → Instant NO-GO
  • Smart Score: Combines all AI results into one score (0-100)
  • Three Brains Vote: Three AI models must agree
  • Confidence: Only says GO if it's very sure (98%+)

Example: Score 95/100 → Three AIs agree → 98% sure → Decision: GO ✓

Reports

Three types of reports

VOID creates 3 types of reports because different people need different things. Some want to read it, some want to print it, some want to feed it to another computer.

1. JSON (For Computers)

Machine-readable data file:

  • All test results in computer format
  • Other software can read it automatically
  • Includes everything: scores, times, errors

2. HTML Dashboard (For People)

Nice web page you can open in browser:

  • Progress bars and charts
  • Green = good, Red = bad (easy to understand!)
  • Click to see more details
  • Works on phone too

3. PDF Certificate (For Printing)

Official paper you can print:

  • Looks like a certificate
  • Has digital signature (can't be faked)
  • Shows: IPC model, score, date, decision (GO/NO-GO)
  • Good for audits and documentation

Where Reports Go

VOID can send reports to different places:

  • Live Website: Watch tests running in real-time
  • Shared Folder: Automatically saved where everyone can see
  • Email: "Your test is finished!" notification
  • API: Other programs can fetch results automatically
  • Slack/Teams: Message to your team chat

How a Test Works (Start to Finish)

9 steps in 48 hours

You plug in an IPC. VOID does these 9 steps. 48 hours later, you get your answer. Here's what happens:

Step 1: Hello, What Do You Have? (15 min)

VOID looks at the IPC: "OK, you have Intel i7, 32GB RAM, NVIDIA GPU, 1TB SSD..."

Step 2: What Should I Test? (10 min)

VOID makes a plan: "I'll test CPU, RAM, GPU, disks... should take 40 hours"

Step 3: Am I Ready? (5 min)

VOID checks itself: "Do I have all tools? Are drivers OK? Temperature normal? Let's go!"

Step 4: Run All Tests (40 hours)

The main work happens here:

  • CPU: Run hard calculations for hours
  • RAM: Write and read patterns, check for errors
  • GPU: Run graphics calculations
  • Disks: Test read/write speed
  • USB/Network: Test all ports
  • Sensors: Watch temperature, fans, voltage all the time

Step 5: Collect Everything (30 min)

VOID gathers all results: "OK, I have 1.2 million data points..."

Step 6: Think About It (3 hours)

The AI brain analyzes everything: "Hmm, CPU is good, RAM is good, but disk is a bit slow..."

Step 7: Make Decision (15 min)

VOID decides: "Overall score: 95/100. Three AIs agree. Confidence 98%. → Decision: GO"

Step 8: Write Reports (1 hour)

VOID creates JSON, HTML, and PDF reports.

Step 9: Tell Everyone (30 min)

Send email, copy to shared folder, update dashboard, notify Slack.

Total Time: ~38-48 hours → You get: GO or NO-GO + detailed reports
